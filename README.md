# GEMPAR PWA

**GEMPAR - Gerakan Memilah Sampah Dari Rumah**

Pilah sampah dari rumah, dapat GEM, banyak manfaat!

## 🚀 Deploy ke GitHub Pages

1. Buat repository baru di GitHub
2. Upload semua file di folder ini ke repository
3. Buka **Settings > Pages**
4. Pilih branch `main` dan folder `/ (root)`
5. Klik **Save**
6. Tunggu beberapa menit, lalu akses URL yang diberikan

## 📁 Struktur File

```
gempar-pwa/
├── index.html          # Halaman utama
├── manifest.json       # Konfigurasi PWA
├── sw.js              # Service Worker
├── favicon.ico        # Favicon
├── icon-192.png       # Icon PWA 192x192
├── icon-512.png       # Icon PWA 512x512
└── images/
    ├── poster.png         # Poster infografis
    ├── mascot-cool.png    # Maskot GEMPAR
    ├── mascot-reward.png  # Maskot Reward
    └── logogempar.png     # Logo GEMPAR (FAB)
```

## ✨ Fitur

- 🌐 PWA (Progressive Web App) - bisa di-install ke layar utama
- 📱 Responsive design - optimal di mobile dan desktop
- 🎨 Animasi scroll reveal
- 🔄 Service Worker untuk caching offline
- 🔔 Install banner otomatis
- ⚡ FAB (Floating Action Button) ke aplikasi GEMPAR
